# graph-visualizer
This is a repository that contains source code of our (web-based) graph visualizer

# System Requirements
Python >= 3.8
fastapi>=0.95.0
uvicorn>=0.22.0
pandas>=1.5.0
python-multipart>=0.0.6

- Install fastapi, uvicorn, pandas, python-multipart
pip install -q fastapi uvicorn pandas python-multipart

- Run the backend first.
- Then browse "http://localhost:8000" for frontend.
